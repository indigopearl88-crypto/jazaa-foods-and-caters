# Jazaa foods and caters

A luxury, high-fidelity, fully responsive catering & event website for **Jazaa foods and caters** located at Iqbal Town Marquee Complex, Main Expressway Highway, near Jugnu Marquee.

---

## 🍽️ Overview

**Jazaa foods and caters** is a premier catering and event production house specializing in:
- **All Types of Events**: Lavish Wedding Banquets (Baraat, Walima, Mehndi), Birthday Parties with bespoke themed setups, and Executive Corporate Events.
- **Lavish Décor**: Royal floral stages, crystal chandeliers, luxury bridal walkways, and fairy light canopies.
- **Authentic Pakistani Foods**: Clay-pot Shinwari karahi, degi mutton biryani, live seekh kebab & boti BBQ stations, freshly baked tandoori naans, badami qorma, and daig home delivery.
- **Chinese Foods with Live Stalls**: Sizzling live wok stations, chicken chow mein, egg fried rice, chicken manchurian, crispy wings, and live soup counters.

---

## 🌟 Key Features

1. **Fully Responsive & Mobile-First**:
   - Custom `max-width: 820px` mobile navigation architecture.
   - Luxury fullscreen mobile slide-over navigation drawer with numbered links and direct contact actions.
   - Adaptive Hero section with auto-positioning arched venue frames.
   - Compact floating WhatsApp button (FAB) for instant mobile inquiries.

2. **Interactive Event & Menu Tools**:
   - **Interactive Menu Selector**: Instant per-head calculation for 1-dish menus, daig delivery, and full event packages (19 stations).
   - **Instant WhatsApp Quote Generator**: Form on the contact page automatically formats event type, catering preferences (Pakistani food / Live Chinese stalls / Grand Feast), date, and guest count directly into WhatsApp.
   - **Google Maps Location Showcase**: Interactive embedded map and one-tap directions link for `(33.6472208, 73.109174)`.

3. **Motion & Interactive Elements**:
   - Scroll-driven Mughal arch expansion.
   - Horizontal drag-and-scroll service showcase.
   - Interactive icon micro-animations reacting dynamically to user clicks.
